# Modpack roadmap summary

The full assessment is in [`2026-08-06-modpack-roadmap-research.md`](2026-08-06-modpack-roadmap-research.md).

Recommended sequence:

```text
repository truth
-> crash-safe Nightmare completion transaction
-> reusable resolution/outcome/appraisal engine
-> modpack manifest and packaging shell
-> minimal infrastructure dependencies
-> one optional ability adapter
-> comparable vertical slice
-> architecture scorecard
-> broader content and progression
```

Highest-priority finding: the custom core is ahead of the modpack layer, and the current critical path is durable Nightmare completion and adapter boundaries rather than installing more content mods.
