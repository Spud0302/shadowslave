# Historical project records

Files in this directory preserve earlier changelog, issue, and testing documents verbatim when their
root-level counterparts are replaced with concise current-state records.

Historical statements describe what was believed, implemented, or tested at the time. They do not
override `PROJECT-STATUS.md`, `docs/CURRENT-PREVIEW-SUMMARY.md`, or the current root documents.
## 2026-10-22 status refresh

The root `README.md`, `PROJECT-STATUS.md`, `ISSUES.md` and `GPT_HANDOFF.md` described the August
modular-alpha state (Kindle, Last Light, Combat Core, PR and issue numbers such as #281–#285 and #34
from the repository's previous history). They were replaced with the current state after the
Aspect-roll and rank-up rework. The August versions are kept here as `*-2026-08-13.md`, and the old
`docs/CURRENT-PREVIEW-SUMMARY.md` as `CURRENT-PREVIEW-SUMMARY-preview2.md`. PR and issue numbers
in them refer to the old history, not to this repository's GitHub numbering.
