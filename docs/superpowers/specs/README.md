# Shadow Slave design specs — historical index

The files in this directory are preserved design records, **not the current runtime contract**.

## `2026-07-28-shadow-slave-mod-design.md`

**Status: HISTORICAL / SUPERSEDED for Phase 1 runtime behaviour.**

That spec predates the later canon verification and several implemented releases. In particular, its
original Phase 1 model says First Nightmare completion produces an **Awakened** player; current canon
research and runtime correctly stop at **Sleeper / Dreamer (Dormant)**.

Do not rewrite the old body to look as though it always knew the later conclusions. Read it as the
record of the design at the time.

For current information use, in order:

1. `../../../README.md` — current shipped datapack behaviour and Phase 1 completion boundary;
2. `../../lore-research/README.md` — canon research index and confidence rules;
3. `../../lore-research/minecraft-implementation-brainstorm.md` — Java migration ideas (proposal,
   not automatically approved design);
4. `../../../docs/ENGINEERING-NOTES.md` — implementation constraints and the incidents behind them;
5. `../../../CHANGELOG.md` — what actually shipped and when.

The old spec remains useful for intent, rejected approaches, and the evolution of the project, but a
statement there that conflicts with the current README or verified lore should be treated as
historical rather than as an instruction to regress the implementation.
