# Section C — Memories

> **Status:** verified working pass.
>
> **Spoilers:** unrestricted.
>
> This section makes one important terminology correction up front: ordinary Memories are stored in and linked to the owner's soul, but they are **not** universally non-transferable `soulbound gear`. A true **Bound / Soulbound** relationship is a rarer special property.

## C1. What is a Memory, in-world? Where do they come from?

**CONFIDENCE: CANON**

A **Memory** is a Woven magical artifact with a specific foundational set of enchantments that let an object exist as soul essence, be stored within an owner's soul, and later be reconstituted as physical matter.

Late weaving explanations clarify that a Memory normally contains foundational patterns for:

- storage inside the soul as essence;
- reconstitution from essence into matter;
- connection to the owner's soul;
- self-repair while dismissed, unless completely destroyed;
- adjustment to the owner's body where relevant;
- plus whatever unique enchantments make the individual artifact special.

Not every enchanted or Woven object is a Memory. `Memory` describes a particular artifact architecture, not simply any magical item.

### Where Memories come from

Known routes include:

1. **Nightmare Spell rewards** after defeating Nightmare Creatures or other significant beings. The reward is not guaranteed after every kill.
2. **Transfer from another owner** by gift, trade, sale, inheritance or organizational issue.
3. **Deliberate creation by Awakened sorcerers/enchanters.** Valor forgemasters mass-produce simpler Memories, while exceptional artisans can alter or create much more sophisticated ones.
4. **Aspect Legacy rewards.** Many Legacy Relics are Memories, although `Legacy Relic` is a broader category and can also be knowledge, an Echo, a Domain fragment or another form.
5. **Exceptional mechanisms**, including growing Memories, Shard Memories and Bound relics.

Sunny's First Nightmare establishes that a Memory may be awarded from a kill within a Nightmare. This should not be simplified into `Nightmare completion always gives a Memory`.

Sources:
- https://shadowslave.fandom.com/wiki/Memory
- https://novelfull.com/shadow-slave/chapter-15.html
- https://novelfull.com/shadow-slave/chapter-2048-different-foundations.html
- Chapter 3024, **Weaving 101**, indexed by the Memory wiki

Notes:
- The Spell is a major creator/distributor of Memories but not their only source.
- A Memory is not necessarily the physical corpse-part of the creature it came from; it is a Woven artifact whose Rank/Tier commonly reflects that source.

## C2. Memory Rank and Tier

**CONFIDENCE: CANON**

Memories have **two separate classifications**.

### Rank

Memory Rank uses the human Soul Rank terminology:

1. Dormant
2. Awakened
3. Ascended
4. Transcendent
5. Supreme
6. Sacred
7. Divine

A Memory can be **higher Rank than its owner**. While still a Dormant Sleeper, Sunny uses Awakened and Ascended Memories.

There is no canon rule that an owner may only possess or summon Memories of their own Rank.

### Creature Rank → Memory Rank

For Spell-awarded Memories originating from Nightmare Creatures, the profane creature Rank maps to the corresponding human-rank vocabulary:

| Creature Rank | Memory Rank |
| --- | --- |
| Dormant | Dormant |
| Awakened | Awakened |
| Fallen | Ascended |
| Corrupted | Transcendent |
| Great | Supreme |
| Cursed | Sacred |
| Unholy | Divine |

Example: the **Fallen Monster Cursed Herald** yields the **Ascended Tier II Dusk Shard**.

Sources:
- https://novelfull.com/shadow-slave/chapter-261-moon-shard.html
- https://shadowslave.fandom.com/wiki/Memory

### Tier

Tier runs from **I to VII** and generally corresponds to the **Class / number of Soul Cores** of the source creature:

| Creature Class | Cores | Typical Memory Tier |
| --- | ---: | ---: |
| Beast | 1 | I |
| Monster | 2 | II |
| Demon | 3 | III |
| Devil | 4 | IV |
| Tyrant | 5 | V |
| Terror | 6 | VI |
| Titan | 7 | VII |

Chapter 74 explicitly explains this seven-tier correspondence while Sunny receives the **Awakened Tier III Midnight Shard** from an Awakened Demon.

Source:
- https://novelfull.com/shadow-slave/chapter-74-midnight-shard.html

### What Tier means structurally

Tier is not simply `number of enchantments`.

A Memory's weave is built around one or more anchors/nexuses. More/higher anchors allow the weave to accommodate greater structural complexity and more demanding enchantments. Higher Tier therefore generally means **greater enchantment capacity**, but exceptions exist:

- one powerful enchantment can consume a large amount of capacity;
- a lower-Tier Memory may contain several relatively cheap enchantments;
- higher Tier does not guarantee that a Memory is more useful in every circumstance.

The safest synthesis is:

```text
Rank = quality/potency of the essence and effects
Tier = structural capacity/complexity of the weave
```

That sentence is **INFERRED**, but it accurately summarizes the direct mechanics.

Sources:
- https://novelfull.com/shadow-slave/chapter-74-midnight-shard.html
- https://shadowslave.fandom.com/wiki/Memory

## C3. How are Memories obtained?

**CONFIDENCE: CANON**

### Spell-awarded kills

The Nightmare Spell may award a Memory after a kill. It is **not guaranteed**.

The source creature's Rank and Class strongly influence Memory Rank/Tier. The actual artifact can contain effects that are thematically connected to the slain being, its history or the circumstances surrounding it.

At higher Ranks the Spell becomes much more selective. Late discussion notes that Supreme Memories are dramatically rarer than Awakened ones, apparently because powerful Memories are vastly more expensive/difficult for the Spell to create.

Source:
- https://shadowslave.fandom.com/wiki/Memory

### Transfer between people

Ordinary Memories can be transferred.

Chapter 54 gives the rule directly: **physical contact is required**. Sunny takes Nephis's hand and wills the Starlight Legion Armor out of his Soul Sea and into hers.

Chapter 74 later shows Nephis transferring the Midnight Shard to Sunny in the same manner.

Sources:
- Chapter 54, **Spoils of War**
- https://novelfull.com/shadow-slave/chapter-74-midnight-shard.html

Therefore a Memory economy naturally exists. Memories can be:

- gifted;
- traded;
- bought/sold;
- issued by organizations;
- passed among allies.

### Crafted Memories

Awakened sorcerers can create Memories deliberately.

Chapter 2048 describes Valor's production pipeline: mundane items can be forged, augmented, enchanted and then given the foundational `Memory` quality. More sophisticated methods can duplicate Memories or transfer particular enchantments between vessels.

Sunny's Weaving can create a Memory from scratch or convert an existing enchanted object into one, as with **Ananke's Mantle**.

Sources:
- https://novelfull.com/shadow-slave/chapter-2048-different-foundations.html
- https://novelfull.com/shadow-slave/chapter-1342-nebulous-mantle.html

## C4. What does `soulbound` mean? Can Memories be traded, lost, stolen, destroyed or upgraded?

**CONFIDENCE: CANON, with terminology correction**

### Ordinary Memories are soul-stored, not permanently soulbound

Ordinary Memories are stored within the Soul Sea and connected to their owner, but they remain **transferable**.

So:

> **`All Memories are soulbound and cannot be traded` is false.**

A better distinction is:

```text
ordinary Memory = soul-stored / soul-linked / transferable
Bound Memory    = intrinsic special bond / exceptional case
```

### True Soulbound / Bound relics

The **Mantle of the Underworld** eventually gains the enchantment **[Soulbound Relic]** after growing from Tier VI to Tier VII.

Sunny then binds it to himself; the external Memory is destroyed and its power becomes the **[Marble Shell]** Attribute. The useful conceptual distinction is that the artifact stops behaving like an ordinary transferable piece of equipment and becomes intrinsic to the wielder.

Later Sunny creates **Blessing** for Nephis using his related Shadowbound method. Its **[Bound]** trait makes the weapon equal in Rank and Class/Tier to the soul of its wielder.

Sources:
- https://novelfull.com/shadow-slave/chapter-972-soulbound.html
- https://novelfull.com/shadow-slave/chapter-2061-soul-sword.html

### Can a Memory be destroyed?

Yes.

Memories regenerate ordinary damage while dismissed, but **complete destruction is permanent**.

Ordinary Memories also normally disappear when the owner dies. **Shard Memories** from the Forgotten Shore are a documented exception: their weave was constructed to survive the death of an owner.

Sources:
- https://shadowslave.fandom.com/wiki/Memory
- https://shadowslave.fandom.com/wiki/Shard_Memory

### Can a Memory be stolen?

**CONFIDENCE: INFERRED / context-dependent**

A physically summoned Memory can obviously be separated from its user in combat, but ownership is soul-based. The normal ownership-change process is **voluntary transfer by physical contact**.

No general rule has been found where simply picking up another person's summoned Memory permanently changes ownership.

Safe statement:

> Memories are **transferable**, but not ordinary Minecraft-style dropped loot whose ownership changes by pickup.

### Can Memories be upgraded?

Yes, but there is **no universal automatic enhancement ladder**.

Distinct mechanisms exist:

1. **Modification / enchantment transplant.** A skilled sorcerer can alter an existing Memory, though modifying Spell-created Memories is unusually difficult.
2. **Rank elevation.** Sunny considers and later performs major redesigns such as elevating the Dawn Shard into the **Crown of Dawn**. Merely replacing a soul shard is not enough; the weave itself must withstand and use stronger essence.
3. **Growing Memories.** Rare artifacts can have explicit growth conditions. The Mantle of the Underworld fills its kill counter and grows from Tier VI to Tier VII, gaining a new enchantment.
4. **Bound scaling.** A Bound relic can scale to the Rank/Class of its wielder rather than being fixed permanently.
5. **Added enchantments.** Sunny later adds **[Blessing of Flesh]** to the Endless Spring.

Sources:
- https://novelfull.com/shadow-slave/chapter-972-soulbound.html
- https://novelfull.com/shadow-slave/chapter-1342-nebulous-mantle.html
- https://novelfull.com/shadow-slave/chapter-2061-soul-sword.html
- https://shadowslave.fandom.com/wiki/Sunny/Memories

## C5. Memory categories and examples

**CONFIDENCE: CANON**

The Spell uses several practical Memory Types.

### Weapon

Weapons include swords, bows, arrows, shields and stranger combat implements.

Examples:

- **Midnight Shard** — Awakened Tier III weapon; becomes more powerful when its wielder is near death and refuses to surrender.
- **Dusk Shard** — Ascended Tier II shield able to change its weight according to its master's will.
- **Sin of Solace** — Transcendent Tier V weapon with a powerful mind-affecting curse.

Sources:
- https://novelfull.com/shadow-slave/chapter-74-midnight-shard.html
- https://novelfull.com/shadow-slave/chapter-261-moon-shard.html
- https://shadowslave.fandom.com/wiki/Sunny/Memories

### Armor

Armor Memories provide supernatural protection and may possess multiple independently summonable layers.

Example:

- **Puppeteer's Shroud** — Awakened Tier V armor with durability, mental protection and essence-related enchantments.

Source:
- https://shadowslave.fandom.com/wiki/Sunny/Memories

### Charm

Charms are small accessories whose value comes almost entirely from enchantments rather than their mundane form.

Examples:

- **Broken Oath** — an Awakened charm that projects a soul-eroding aura.
- **Essence Pearl** — charm allowing underwater breathing/vision.

Sources:
- https://shadowslave.fandom.com/wiki/Memory
- https://novelfull.com/shadow-slave/chapter-974-shadow-in-the-shell.html

### Tool / Utility Memory

Utility Memories perform non-standard functions and form an important part of an Awakened arsenal.

Examples:

- **Endless Spring** — produces water and later gains an additional recovery enchantment.
- **Covetous Coffer** — spatial storage and transformation utility.
- **Dawn Shard / Crown of Dawn** — empowers other Memories around it.

Sources:
- https://novelfull.com/shadow-slave/chapter-104-soul-arsenal.html
- https://shadowslave.fandom.com/wiki/Sunny/Memories
- https://shadowslave.fandom.com/wiki/Shard_Memory

### Garment

Garments are rarer, generally less defensive than armor, but can normally be worn **at the same time as an Armor Memory**.

Example:

- **Ananke's Mantle** — Transcendent Tier I Garment.

Source:
- https://novelfull.com/shadow-slave/chapter-1342-nebulous-mantle.html

### Lineage Memory

Lineage Memories are special consumable Memories that can impart hereditary supernatural Attributes/lineages.

They should not be treated as an ordinary equipment category.

Source:
- https://shadowslave.fandom.com/wiki/Memory

### Shard Memory

Shard Memories are Forgotten-Shore-specific artifacts with exceptional weave properties, including surviving owner death and participating in the Oath Key mechanism.

Source:
- https://shadowslave.fandom.com/wiki/Shard_Memory

Notes:
- The categories are functional labels, not rigid MMO equipment slots.
- Exotic items can behave in unusual ways even while being labeled `Weapon`, `Tool`, etc.

## C6. How do Memories improve? Is there an enchantment/awakening system?

**CONFIDENCE: CANON**

There is no universal `Memory XP → level up` mechanic.

Improvement depends on how the particular Memory was made.

### Enchantments

Each Memory can carry one or more named enchantments.

Enchantments may be:

- passive;
- activated using soul essence;
- conditional;
- aura-based;
- self-targeting/cursed;
- limited by special conditions to increase potency;
- transplanted or modified by sufficiently advanced sorcery.

Most Awakened do **not** automatically receive a perfect tooltip explaining every enchantment. They often rely on the Spell's descriptions, vague intuitive impressions and experimentation. Certain information-oriented Aspects can reveal more.

### Capacity and compatibility matter

Adding an enchantment is not simply `one empty slot = one enchantment`.

The weave must have enough:

- Tier/capacity;
- Rank/intensity tolerance;
- compatible nature;
- suitable anchors/materials.

A protection-themed Memory may simply be fundamentally incompatible with a destructive self-annihilation enchantment regardless of nominal capacity.

### Growing Memories

Some exceptional Memories possess their own advancement condition.

The Mantle of the Underworld's kill-counter enchantment is a clear example. Completing the condition grows it from Tier VI to Tier VII and grants **[Soulbound Relic]**.

Such growth is rare and should not be assumed to apply to every Memory.

### Bound scaling

A Bound relic can use the owner's soul itself as the scaling reference. Blessing's Bound trait makes it equivalent in Rank/Class to Nephis's soul.

## C7. How does an Awakened carry/access Memories? Is there a soul inventory and are there limits?

**CONFIDENCE: CANON for storage/summoning; UNKNOWN for any universal numeric carrying cap**

### Soul storage

Yes: Memories are stored within the owner's **Soul Sea** as essence.

Sunny repeatedly sees them there as spheres/lights orbiting his Soul Core(s). After acquiring many artifacts, he can possess **hundreds of Memories** at once.

This is a real canonical analogue of a soul inventory, although the novel does not present it as a grid of slots.

Sources:
- https://novelfull.com/shadow-slave/chapter-352-monster-core.html
- https://shadowslave.fandom.com/wiki/Soul_Sea

### Summoning

A Memory is summoned by converting/reconstituting its stored essence into physical matter. This normally takes a short amount of time represented by the formation of sparks/light; particular enchantments can make summoning exceptionally fast or otherwise alter the process.

Dismissal converts it back into essence and returns it to soul storage.

If a dismissed Memory is too far from its master, the essence invested in its manifestation can be lost/wasted and must regenerate rather than returning cleanly.

Source:
- https://shadowslave.fandom.com/wiki/Memory

### Is there a maximum number held?

**UNKNOWN: no universal numeric limit has been found.**

Sunny demonstrably stores hundreds. The practical limits described in the story are instead things such as:

- obtaining the Memories in the first place;
- essence required to activate/sustain powerful enchantments;
- compatibility and usefulness;
- summon time;
- cognitive/logistical ability to use a large arsenal effectively.

No canon equivalent of `36 Memory slots` or `only X equipped Memories` has been found.

### Ordinary physical objects are different

A Memory can be stored in the soul because its weave gives it that property. An ordinary backpack full of mundane items does **not** automatically enter soul storage with it.

This is why spatial-storage Memories like the **Covetous Coffer** are useful: they possess special enchantments allowing them to retain stored inanimate objects while dismissed.

Later Supreme beings can acquire a more general ability to store ordinary physical objects in their Soul Sea, but that is not the baseline Memory mechanic of lower-rank Awakened.

Sources:
- https://shadowslave.fandom.com/wiki/Memory
- https://shadowslave.fandom.com/wiki/Soul_Sea
- https://shadowslave.fandom.com/wiki/Sunny/Memories

# Corrections to existing project shorthand

1. **`Soulbound gear` is too broad.** Ordinary Memories are soul-stored but transferable. `Bound/Soulbound` is a rarer special property.
2. **Rank and Tier are separate.** Rank corresponds to essence quality/source Rank; Tier corresponds broadly to source Class/weave capacity.
3. **Tier is not exactly enchantment count.** It is structural capacity, and exceptions exist.
4. **No universal Memory upgrade station/system exists.** Some are modified by sorcery, some grow, some are elevated, some are Bound, most simply remain what they are.
5. **There is a canon soul inventory, but no verified numeric slot cap.**
6. **Memories are transferable rather than Minecraft-style lootable.** Ownership normally changes deliberately through physical-contact transfer.

# Design consequences — proposals, not canon

The project owner has explicitly allowed implementation/design suggestions on this branch.

## 1. Treat Rank and Tier as two real item dimensions

A single `rarity` number loses one of the most distinctive parts of the setting.

A clean item model would track at least:

```text
memory_rank: 0..6
memory_tier: 1..7
memory_type
enchantments[]
owner / bound-state
```

Rank can govern raw potency/essence scaling while Tier governs enchantment budget/complexity.

## 2. Ordinary Memories should not use Minecraft Curse of Binding semantics

Normal Memories need to be tradable.

A true Bound relic should be a **separate exceptional state** with rules closer to an intrinsic Attribute than ordinary equipment.

## 3. Soul storage should be separate from the vanilla inventory

The canonical fantasy is strong enough to justify a dedicated Memory arsenal:

- summon/dismiss rather than carry stacks physically;
- no ordinary item dropping on player death;
- deliberate transfer UI/action between players;
- possibly no hard slot cap, with usability instead constrained by essence and summon rules.

## 4. Tier is an excellent enchantment-complexity budget

Instead of `Tier III = exactly three enchantments`, assign enchantments a structural cost.

For example, a very strong enchantment could consume most of a Tier III budget while several small passive effects could coexist on the same Memory.

That matches the novel better and enables unusual low-Tier artifacts.

## 5. Do not make all Memory effects known instantly

The novel repeatedly leaves characters experimenting to discover an artifact's practical limits.

A future system could distinguish:

- Spell-provided name/description;
- known enchantment names;
- exact effect values/conditions discovered by use;
- information Aspects that reveal these immediately.

## 6. Rare growth archetypes should be authored properties

Rather than every Memory having XP, specific Memories can have a `growth_condition`:

- kills;
- fulfilled oaths;
- exposure to a source element;
- protecting a wielder;
- other narrative conditions.

Completing the condition can increase Tier, add an enchantment, transform the artifact or unlock Bound status.

# Open questions

1. Exact general probability/model by which the Spell decides whether a kill awards a Memory.
2. Whether any hard metaphysical maximum number of ordinary Memories can be stored in a non-Supreme soul; no numeric cap has been found.
3. Full formal rules for Memory ownership when a summoned artifact is physically separated from its owner for an extreme duration/distance.
4. Whether all ordinary Memories necessarily disappear on owner death in every era/source, or whether additional exceptional weave families besides Shard Memories exist.
5. Full modern taxonomy of custom Forgery schools and what portions of the standard Memory weave each can reproduce.

# Things I did not ask about that matter

1. **High-Rank Memories run into Will.** At Sacred-level conflict, an artifact with no Will of its own can be suppressed by a stronger being's Will; power is no longer just numerical Rank/Tier.
2. **Artificial limitations can make enchantments stronger.** Restricting when/how a Memory works can concentrate its effect enough to bend rules it otherwise could not.
3. **Memory manufacture competes with human progression for Soul Shards.** A shard spent as an artifact nexus is a shard that could have strengthened an Awakened's core, making mass-produced custom Memories economically expensive.
4. **The ability to store objects in the soul is itself extraordinary.** Memories effectively give low-rank Awakened a capability that ordinary souls would not naturally possess until vastly later development.
