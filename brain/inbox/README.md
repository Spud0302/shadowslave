# Idea inbox

Create one file per idea using [[brain/templates/idea|the idea template]]. Do not use one shared scratchpad; separate files reduce merge conflicts and make proposals independently reviewable.

Filename:

    YYYYMMDDTHHMMSSZ--author--short-slug.md

New ideas default to:

- authority: proposal
- lore_class: UNKNOWN or DESIGN
- state: proposed

An idea does not enter active scope until it has an accepted decision, a bounded experiment, and an owner.
