# Task claims

Before substantive write work, inspect this folder and compare every active claim's targets and conceptual scope.

Create a claim from [[brain/templates/task-claim|the task-claim template]] named:

    YYYYMMDDTHHMMSSZ--agent--short-slug.md

Required:

- unique task_id;
- agent and tool;
- exact branch and worktree;
- targets and excludes;
- acceptance criteria;
- lease_until;
- dependencies and overlapping claims;
- state: active, blocked, closed, or expired.

Only the claiming agent edits its claim. A second agent that needs overlap must coordinate first and record that agreement in both claims or a new decision.

Closing a claim does not prove success. The evidence and handoff carry the result.
