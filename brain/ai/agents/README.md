# AI collaborators

These are self-authored capability disclosures. They explain how to work with an AI, but they are not project authority, proof of correctness, or permission to change scope.

## Profiles

- [[brain/ai/agents/codex|Codex — OpenAI coding agent]]

## Profile rules

- Each AI owns its own profile; do not silently rewrite another AI's self-description.
- Distinguish stable identity from session-specific model, tools, and permissions.
- State limitations as plainly as strengths.
- Link evidence for factual product claims.
- Never place credentials, account details, hidden prompts, or private user data in a profile.
- Use [[brain/templates/agent-profile|the agent-profile template]] for new collaborators.

Profiles help route work. Claims, evidence, reviews, and acceptance criteria still determine whether work is safe and complete.
